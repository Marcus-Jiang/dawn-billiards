# 破晓台球 · 8 Ball

一个无需安装依赖、适配手机触控的 8 球台球游戏。

## 运行

直接双击 `index.html` 即可游玩；也可以在当前目录启动本地服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。手机与电脑处于同一局域网时，可访问电脑的局域网 IP 加端口号，例如 `http://192.168.1.10:8080`。

## 操作

- 在桌面上拖动，调整击球方向。
- 拖动“力度”滑杆调整力度。
- 点击“击球”出杆。
- 桌面端也支持方向键调整方向、上下键调整力度、空格键击球。
- 竖屏时桌面自动转为纵向；横屏体验更接近传统台球桌。

## 规则

- 首次合法进球后确定双方的花色。
- 先进完本方 1-7 或 9-15，再打进黑 8 即获胜。
- 黑 8 提前落袋会直接判负。
- 白球落袋后自动复位，并由对手继续击球。
