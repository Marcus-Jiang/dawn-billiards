# 破晓台球 · 8球 / 9球 / 斯诺克

一个无需安装依赖、适配手机触控并支持离线游玩的台球游戏。

## 游戏模式

- **8 球**：首次合法进球后确定全色或花色，清空本方球组后打进黑 8 获胜。
- **9 球**：每一杆必须先碰到台面最小号球，合法打进 9 号球直接获胜。
- **斯诺克**：红球与彩球交替得分，红球清完后按黄、绿、咖啡、蓝、粉、黑顺序清彩；包含基础犯规罚分和彩球重摆。

## 离线游玩

游戏使用 PWA 和 Service Worker 缓存全部代码、样式、脚本与图标：

1. 首次通过 HTTPS 或 `localhost` 打开游戏，等待页面显示“已缓存 · 断网也能玩”。
2. Android Chrome 可点击顶部下载按钮，将游戏安装到主屏幕。
3. iPhone Safari 可点击“分享” > “添加到主屏幕”。
4. 安装或完成首次缓存后，即使断网也能继续游玩。

## 本地运行

直接双击 `index.html` 可以体验游戏，但 Service Worker 离线缓存需要 HTTP 环境：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。手机与电脑处于同一局域网时，可访问电脑的局域网 IP 加端口号，例如 `http://192.168.1.10:8080`。

## 操作

- 在桌面上拖动，调整击球方向。
- 拖动“力度”滑杆调整力度。
- 点击“击球”出杆。
- 桌面端支持方向键调整方向、上下键调整力度、空格键击球。
- 竖屏时桌面自动转为纵向；横屏更接近传统球桌比例。

## Vercel 部署

仓库可直接导入 Vercel，无需构建命令：

- Framework Preset：`Other`
- Root Directory：`./`
- Build Command：留空
- Output Directory：留空

Vercel 会自动使用 `vercel.json` 为 Service Worker 设置正确的缓存响应头。
